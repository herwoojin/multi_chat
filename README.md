> **한 줄 요약** — 누가 어떤 언어로 말하든 **메시지마다 언어를 자동 감지**해서,
> 보는 사람이 설정한 언어로 번역해 **화면에 띄우고 소리로 읽어주는** 채팅 웹앱.

이름 `말.통`은 작업용 가칭이며 자유롭게 바꾸세요.

## 🎯 이 앱이 기존 챗.첵과 다른 단 하나의 핵심

기존 meet4u 챗.첵은 **보낸 사람의 프로필 언어 설정**을 메시지의 원문 언어로 기록합니다.
그래서 한국어로 설정한 사람이 영어로 "Awesome" 이라고 쓰면 그 메시지는
`sourceLanguage: 'ko'` 로 저장되고, 한국어 사용자에게는 "원문과 같은 언어" 로 판정되어
번역이 통째로 건너뛰어집니다. 화면에는 🇰🇷한국어 뱃지가 붙은 영어 문장이 남습니다.

**말.통은 메시지 하나하나를 실제로 감지합니다.**

```
기존:  원문 언어 = 보낸 사람의 설정값          ← 사람이 바꿔 말하면 깨짐
말.통: 원문 언어 = 그 메시지를 실제로 감지한 값  ← 문장마다 독립적으로 맞음
```

감지와 번역을 **한 번의 요청으로 동시에** 받아오기 때문에 비용도 늘지 않습니다
(`sl=auto` 응답에 감지 결과가 함께 들어옵니다 — `TRD.md` 4.2 참고).

## 💰 비용

전 구간 무료 티어 안에서 동작하도록 설계했습니다.

| 항목 | 수단 | 비용 |
|---|---|---|
| 언어 감지 + 번역 | Google Translate `client=gtx` | 0원 (키 불필요) |
| 음성 합성(TTS) | Google Translate TTS + Web Speech | 0원 |
| 음성 입력(STT) | Web Speech Recognition (브라우저 내장) | 0원 |
| 실시간 DB·인증 | Firebase 무료 티어 | 0원 |
| 호스팅·서버리스 | Netlify 무료 티어 | 0원 |

유료 전환이 필요한 지점과 한도 초과 시 증상은 `TRD.md` 10장에 정리했습니다.

## 🛠️ 로컬 개발 (2026-10-18 구현 완료)

| 명령 | 하는 일 | 필요한 것 |
|---|---|---|
| `npm run dev:local` | **실제 Firebase 없이 전체 앱 실행** — Auth·Firestore·Storage 에뮬레이터(`demo-maltong`) + Vite + Functions(`/api/*`) | Java (`brew install openjdk`), Firebase CLI |
| `npm run dev` | 실제 Firebase 프로젝트에 붙어 실행 | `.env` (`.env.example` 참고) |
| `npm run build` | 배포 빌드 (`dist/`) | — |
| `npm run deploy:rules` | 규칙·인덱스 배포 | Firebase CLI 로그인 |

- 앱: http://localhost:5173 (같은 Wi-Fi 휴대폰은 터미널의 Network 주소)
- 에뮬레이터 UI: http://localhost:4010 — 만들어진 사용자·방·메시지를 직접 볼 수 있다
- `dev:local` 을 Ctrl+C 로 끄면 테스트 데이터가 `.emulator-data/` 에 저장되고 다음 실행 때 다시 불러온다
- 번역·TTS 는 에뮬레이터 모드에서도 실제 Google 엔드포인트를 쓴다 (인터넷 필요)

기술 구성과 한계는 [`TECH_STACK.md`](./TECH_STACK.md) 참고.
